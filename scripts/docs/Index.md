# Bash Scripting Fundamentals

A practical guide to writing Bash scripts, starting from the basics and building up to patterns you'll use in real scripts.

| 1 | [Variables & Parameters](Bash-Scripting-Fundamentals/Variables-and-Parameters.md) | Storing data, arrays, passing arguments, string manipulation |

| 3 | [Functions & Inputs](Bash-Scripting-Fundamentals/Functions-and-Inputs.md) | Reusable code blocks, argument parsing with flags |

Once you're comfortable with the fundamentals, see [Production-Quality Script Standards](Production-Quality-Script-Standards.md) for guidelines on writing scripts that are ready for real use.
